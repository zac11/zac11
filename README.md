## 🧠 About Me

I'm a **Senior / Lead AI Engineer** architecting production **multi-agent systems, retrieval-augmented generation (RAG) pipelines, and LLM evaluation frameworks**. With deep roots in software quality engineering and systems reliability, I focus on turning non-deterministic foundation models into **observable, testable, production-grade AI systems**.

- 🔭 **Building:** Autonomous multi-agent workflows, hybrid RAG architectures, and generative UI interfaces (**A2UI**, **MCP**)
- 🧪 **Specializing in:** LLM & Agent Evaluation (**RAGAS**, **DeepEval**), observability, and deterministic guardrails
- ✍️ **Writing:** Deep dives on AI architecture, agentic engineering, and LLMOps at [**zac11.dev/blog**](https://zac11.dev/blog)

---

## 🏗️ Core Engineering Focus

- **Multi-Agent Orchestration:** Designing stateful, tool-using agent graphs, human-in-the-loop workflows, and Model Context Protocol (**MCP**) integrations.
- **Production RAG & Knowledge Systems:** End-to-end ingestion, semantic chunking, hybrid dense + BM25 retrieval, cross-encoder reranking, and vector indexing.
- **LLM Evaluation & LLMOps:** Automated faithfulness/relevance benchmarking, regression testing for prompts and agents, latency/cost optimization, and tracing.
- **Fine-Tuning & Inference:** Task-specific adaptation with **LoRA / QLoRA**, structured output enforcement, and self-hosted model serving.
